# Güvenlik Politikası

WinCare Manager dosyalara, kayıt defterine ve Windows ayarlarına dokunan bir araçtır. Bu nedenle güvenlik hatalarını ciddiye alıyoruz.

## Güvenlik açığı bildirme

Güvenlik açıklarını **herkese açık Issue olarak bildirmeyin.** Bunun yerine GitHub'daki **Security → Report a vulnerability** (özel güvenlik bildirimi) özelliğini kullanın.

Bildiriminizde şunlar olsun:
- etkilenen sürüm,
- sorunu yeniden oluşturma adımları,
- olası etkisi (ör. korunan bir klasörün silinebilmesi, yedek atlanarak değişiklik yapılabilmesi).

## Kapsamdaki örnekler

- Korunan Windows klasörlerinin veya sembolik bağlantı hedeflerinin temizlik kapsamına girmesi
- Deneme modu açıkken sistemde değişiklik yapılması
- Yedek alınmadan veya bozuk bir yedekle geri yükleme yapılabilmesi
- Yönetici yetkisi kontrolünün atlatılması

## Desteklenen sürümler

Yalnızca en son yayınlanan sürüm güvenlik düzeltmesi alır.
